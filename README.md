## Overview

InterviewAce AI is an intelligent placement preparation platform that simulates real interview experiences using Google Gemini AI. It provides realistic HR, Technical, Behavioral, and Coding interviews, evaluates responses, analyzes resumes using ATS standards, and tracks user performance through interactive dashboards.

## Features

- AI Mock Interviews
- Resume ATS Scanner
- Coding Practice
- Company-Specific Preparation
- Placement Learning Hub
- Analytics Dashboard
- Progress Tracking
- Study Planner
- Firebase Authentication
- Responsive Design

## Installation

```bash
npm install
```

Create a `.env.local` file and add your Firebase configuration and Gemini API key.

Run the application:

```bash
npm run dev
```
